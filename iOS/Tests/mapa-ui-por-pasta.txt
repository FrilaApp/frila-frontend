# Mapa de caminho para testes de interface do PR (Scripts/testes-de-interface-do-pr.sh).
#
# `prefixo = destino, destino, ...` (caminho relativo a iOS/). Prefixo com `/` no fim = a pasta; sem `/` = o
# arquivo; com `*` = glob (`*` vale por qualquer trecho, inclusive `/`). Um arquivo alterado casa com as linhas
# cujo prefixo o cobre e vale a mais específica (a de mais caracteres fixos: o arquivo ou o glob ganha da pasta
# dele; empate soma os destinos). Para um arquivo ter mais que o marcador da pasta, repita o marcador na linha
# específica. Destinos:
#   Classe       classe de interface do alvo FrilaUITests (roda inteira)
#   @visual      o marcador abaixo (acessibilidade, captura e conferência visual)
#   @fumaca      nada além da fumaça (Tests/fumaca-ui.txt): os unitários e o conferir-textos cobrem
#   @completa    a suíte inteira de interface (FrilaUITests)
# Caminho de iOS/Sources (ou de qualquer outra pasta de iOS/ que muda o app) que NENHUMA linha cobre
# vai para a suíte inteira: na dúvida, tudo. Arquivo de iOS/Tests/UI/X.swift alterado roda as classes
# dele, sem precisar de linha aqui.
#
# O `conferir` reprova prefixo que não existe no disco, classe que não existe, e classe de interface
# que não está em nenhum destino, no marcador @visual, na fumaça nem em @so-noturna.
